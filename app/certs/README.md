# Сертификаты своих серверов

Сюда перед сборкой кладут сертификат сервера карт, которому приложение
должно доверять, в формате PEM (`*.pem` или `*.crt`):

- **стенд:** `infra/tls/server.crt` со стенда (самоподписанный, `make-dev-cert.sh`);
- **релиз:** корневой сертификат внутреннего УЦ.

```sh
scp <стенд>:/opt/sabyrmap/infra/tls/server.crt app/certs/stand.crt
```

Сертификат попадает в приложение двумя путями:

- в Dart (API, каталог карт, скачивание регионов) как asset `certs/`,
  его подключает `lib/net/trusted_certificates.dart` при старте;
- в Android (MapLibre: тайлы, стили) как `res/raw/server_ca.pem` и
  `network_security_config.xml`, которые генерирует `android/app/build.gradle.kts`.

Доверие добавляется к системным УЦ, системные остаются. Если папка пуста,
приложение работает как раньше. Файлы `*.pem`/`*.crt` не хранятся в git:
у каждого стенда свой сертификат. После замены сертификата приложение нужно
пересобрать.
